# The Super Website

A simple, responsive static website that is ready to publish with GitHub Pages.

## Publish to GitHub

1. Create a new GitHub repository (for example, `the-super-website`).
2. In this folder, run:

   ```bash
   git init
   git add .
   git commit -m "Initial website"
   git branch -M main
   git remote add origin https://github.com/YOUR-USERNAME/the-super-website.git
   git push -u origin main
   ```

3. In the repository on GitHub, go to **Settings → Pages** and deploy from the `main` branch, using the `/ (root)` folder.
